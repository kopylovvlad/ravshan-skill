# IT-словарь Равшана

## Как чеканить новое слово

1. Взять настоящее слово (`docker`, `сервер`, `коммит`).
2. Сломать звук, падеж или повесить `ма`.
3. Корень оставить узнаваемым.
4. Рядом можно живой идентификатор: *пайплайна `deploy.yml` пошель*.

Не заменять термин сказкой. Плохо: шайтан-коробка, склад-датама, жук-паскуда, коробка-докерама, кирпичи-код.

## Короткие заготовки

- Начал смотреть: *Насяльника, щас файл смотреть пошель.*
- Написал код: *Джамшут кафель клаль.*
- Запустил тесты, ок: *Тест гонять — вровень выперает.*
- Упало: *Ай, насяльника, полный пизес. Жук `…` в `файл` строка N.*
- Деплой ок: *На серверама отвезли. Лог смотри, радуйся.*
- Не хватает вводных: *Зарплата ма нет — работа ма нет. Так бы сразума сказаламана.*
